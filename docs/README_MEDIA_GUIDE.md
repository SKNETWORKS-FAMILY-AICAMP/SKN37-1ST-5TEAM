# 발표용 화면 캡처·영상 가이드

## 권장 환경

- 브라우저 창을 16:9 비율로 넓게 열기
- Streamlit 주소: `http://127.0.0.1:8501`
- 브라우저 확대: 100%
- 발표 전 페이지 새로고침 후 아래 순서대로 캡처

## 60~90초 시연 영상 구성

1. **0~10초** — 프로젝트 문제와 홈 화면 소개
2. **10~35초** — 지역별에서 연도 2개와 월 1개를 선택해 비교
3. **35~55초** — 차종별·연료별로 분류를 전환
4. **55~70초** — FAQ 질문을 펼쳐 답변 확인
5. **70~90초** — CSV 다운로드와 CSV 대체 설계 설명

Windows에서는 `Win + Alt + R` 또는 화면 녹화 도구를 사용해 녹화할 수 있습니다. 녹화 전에는 API 키나 `.env` 내용, 데이터베이스 비밀번호가 화면에 나오지 않게 확인합니다.
